# RF-25 — Autorizar repetición excepcional

RF-25 Participación Autorizar repetición excepcional El sistema impide repetir una participación registrada, salvo autorización del docente creador del caso; tampoco permite participar en una sesión finalizada.

**Veredicto integral: BLOQUEADO.** Permiso individual de un uso disponible; consumo por inicio productivo y vinculación de caso distinto siguen pendientes.

## Implementación reutilizada

Proxy/ServicioExcepciones y permiso_intento_extra nativo reutilizados; cupo uno y fecha original en replay; guard SQL de consumo

## Preparación y superficie

`preparar-27rf.ps1 -RF RF-25`. Modo principal; PostgreSQL17 nuevo, JWT reales. Cuentas, matrículas, grants y asignación son datos administrativos sintéticos. Consentimiento/inicio permanecen en LAB cuando la URL usa base_url_laboratorio. No implica registro de esas rutas en app.main.
