# RF-21 — Notificar convocatoria y cambios

RF-21 Notificaciones Notificar convocatoria y cambios El correo informa caso, mensaje personalizado, URL y código. El docente puede agregar o retirar estudiantes y cada afectado debe ser notificado.

**Veredicto integral: APROBADO.** El recorrido de aceptación y sus negativas aprobaron; ver límites del entorno.
