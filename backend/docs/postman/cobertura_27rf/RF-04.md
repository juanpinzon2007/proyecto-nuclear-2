# RF-04 — Asociar espacio académico y estudiantes

RF-04 Organización académica Asociar espacio académico y estudiantes Al agendar un caso, el docente asocia el nombre del espacio académico y uno o varios estudiantes autorizados.

**Veredicto integral: BLOQUEADO.** Asociaciones y grants explícitos requieren preparación administrativa; falta una API aprobada de vinculación docente/grupo/asignación. No se confunde agendar sesión con crear ese vínculo.

## Implementación reutilizada

Scheduling/Identity: espacio_academico, docente_espacio_academico, grupo_academico/grupo_estudiante, asignacion_caso y convocatoria; `convocation_management.py::_autorizar`

## Preparación y superficie

`preparar-27rf.ps1 -RF RF-04`. Modo principal; PostgreSQL17 nuevo, JWT reales. Cuentas, matrículas, grants y asignación son datos administrativos sintéticos. Consentimiento/inicio permanecen en LAB cuando la URL usa base_url_laboratorio. No implica registro de esas rutas en app.main.
