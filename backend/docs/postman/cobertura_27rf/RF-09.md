# RF-09 — Validar estructura y rúbrica del caso

RF-09 Validación Validar estructura y rúbrica del caso Todo caso nuevo inicia como Borrador. Debe cumplir estructura académica y tener rúbrica asociada antes de publicarse. Solo casos publicados pueden agendarse; el docente puede archivar casos para evitar nuevas programaciones.
