# RF-23 — Controlar tiempo máximo

RF-23 Participación Controlar tiempo máximo Al iniciar la participación, el sistema inicia el contador, aplica el límite máximo y conserva las respuestas para evaluación.

**Veredicto integral: BLOQUEADO.** Contador y vencimiento de intentos existentes tienen pruebas; el inicio productivo que lo activa permanece cerrado. Se acredita recorrido LAB, no requisito integral productivo.

## Implementación reutilizada

Intento, reloj inyectado, snapshot duracion_concedida_segundos, cierre y guards

## Preparación y superficie

`preparar-27rf.ps1 -RF RF-23`. Modo principal; PostgreSQL17 nuevo, JWT reales. Cuentas, matrículas, grants y asignación son datos administrativos sintéticos. Consentimiento/inicio permanecen en LAB cuando la URL usa base_url_laboratorio. No implica registro de esas rutas en app.main.
