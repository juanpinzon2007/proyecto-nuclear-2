# RF-27 — Notificar calificaciones y feedback

RF-27 Notificaciones Notificar calificaciones y feedback El sistema notifica al estudiante su nota y envía una notificación dentro del sistema cuando el docente agregue retroalimentación.

**Aceptación técnica MVP: APROBADO.** El recorrido de aceptación y sus negativas aprobaron; ver límites del entorno.

## Implementación reutilizada
