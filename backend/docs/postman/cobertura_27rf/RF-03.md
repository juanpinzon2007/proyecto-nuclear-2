# RF-03 — Administrar docentes, roles y permisos

RF-03 Acceso Administrar docentes, roles y permisos El administrador crea usuarios docentes y les asigna roles y permisos.

**Veredicto integral: BLOQUEADO.** Alta, consulta y validación del perfil del catálogo están acreditadas. Falta precisar la configuración/asignación operativa de permisos globales por rol frente a excepciones individuales. Multirrol y DOCENTE ADMINISTRADOR no se presuponen requisitos expresos del RF original.

## Alcance real del incremento

Las pruebas nuevas de transacción corresponden a test_admin_write_authorization.py en unidad e integración. Cuatro solicitudes antes aceptadas tras revocar al administrador ahora devuelven 401/403 sin mutación. Hay evidencia PG de Session precargada, locks concurrentes observados y rollback de SQL posterior al INSERT. No se modifica el catálogo o la cardinalidad de roles.

El rol DOCENTE con permiso CREAR_CASOS es precondición explícita LAB, no un permiso por defecto de producción. El administrador no puede usar PUT individual para cambiar rol_permiso global ni para representar excepciones no aprobadas. Pendiente decidir esa semántica operativa. Multirrol por cuenta y DOCENTE ADMINISTRADOR no se derivan del mero enunciado plural. Informe: backend/docs/RF03_AUTORIZACION_TRANSACCIONAL.md.
