# RF-20 — Asignar y validar código de autorización

RF-20 Acceso Asignar y validar código de autorización El sistema asocia un código de autorización al estudiante convocado e incluye el código en la notificación de programación.

**Veredicto integral: BLOQUEADO.** Código de una sola entrega y hash sí; falta entrega externa segura al estudiante. Una notificación interna no es correo.

## Implementación reutilizada

Scheduling `crear_convocatoria`, hash y Identity ValidadorConvocatoriaScheduling

## Preparación y superficie

`preparar-27rf.ps1 -RF RF-20`. Modo principal; PostgreSQL17 nuevo, JWT reales. Cuentas, matrículas, grants y asignación son datos administrativos sintéticos. Consentimiento/inicio permanecen en LAB cuando la URL usa base_url_laboratorio. No implica registro de esas rutas en app.main.
