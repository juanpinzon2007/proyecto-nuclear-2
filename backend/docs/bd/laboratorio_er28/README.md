## Traducción DBML → SQL

- int → INTEGER; varchar/text/boolean conservan tipo/límite.
- timestamp → TIMESTAMP WITHOUT TIME ZONE; decimal(p,s) → NUMERIC(p,s), alias nativo sin cambio de precisión.
- increment → GENERATED BY DEFAULT AS IDENTITY sobre INTEGER. Permite PK explícitas sintéticas como el autoincremental original; genera secuencias propias, no tablas auxiliares.
- PK simples/compuestas, UNIQUE de columna/bloque y las 40 FK se expresan como constraints con nombres técnicos deterministas.
- Las FK sin acciones especificadas conservan PostgreSQL NO ACTION, MATCH SIMPLE, no diferibles; no se agregan cascadas.
- Los bloques indexes originales solo declaran PK/UNIQUE: PostgreSQL crea sus 47 índices únicos de soporte. No se inventan índices no únicos.
- Defaults literales originales se conservan. No hay CHECK ni triggers de usuario nuevos. Los triggers internos de PostgreSQL para FK no son reglas añadidas por el experimento.
- BEGIN/COMMIT envuelve la creación; no hay CREATE DATABASE, DROP, ALTER, backfill ni tabla de control de migración en el SQL experimental. La base vacía la crea la imagen en el contenedor nuevo.
