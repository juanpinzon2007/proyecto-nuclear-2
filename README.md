# Proyecto Nuclear 2

Repositorio colaborativo para el desarrollo del **Proyecto Nuclear 2**.

---

## Estructura de Ramas del Equipo

Para garantizar un flujo de trabajo ordenado y colaborativo, el repositorio cuenta con las siguientes ramas asignadas para cada integrante:

* **`main`**: Rama principal y estable del proyecto.
* **`alejandro`**: Rama de trabajo asignada a Alejandro.
* **`juan`**: Rama de trabajo asignada a Juan.
* **`maicol`**: Rama de trabajo asignada a Maicol.
* **`martin`**: Rama de trabajo asignada a Martin.

---

## Normas Básicas de Trabajo
1. Trabajar los desarrollos individuales en la rama correspondiente a cada integrante.
2. Mantener mensajes de commit claros y descriptivos.
3. Integrar los cambios mediante Pull Requests y revisiones antes de fusionar.
