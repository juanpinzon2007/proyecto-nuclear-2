# Frontend SPS

Aquí se desarrollará la aplicación Angular. Esta entrega solo reserva su ubicación;
no contiene componentes, pantallas ni módulos funcionales.

Cuando exista la aplicación, el equipo acordará la versión de Angular y Node,
añadirá su Dockerfile y registrará el servicio frontend en Docker Compose.
La comunicación con la API se hará mediante HTTP, sin acceso directo a PostgreSQL.
